# Contributing to the Geek Protocol profile

This repository maintains the **GEEKProtocol0110 GitHub profile**, its banner and supporting project navigation. It is a documentation repository; it has no application runtime or npm test suite.

## Choose the right project

- [Geek Protocol HQ](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/CONTRIBUTING.md): learning, gameplay, player profiles, Kaspa integration and current protocol documentation.
- [Geek Jr](https://github.com/GEEKProtocol0110/geek-jr/blob/main/CONTRIBUTING.md): family learning activities, word cards and reading.
- [Geek Mini](https://github.com/GEEKProtocol0110/geek-mini): the shareable Kaspa challenge and embed; its README provides development checks.

File product bugs and proposals in the relevant project. For private security concerns, follow [SECURITY.md](SECURITY.md). Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Improve this profile

1. Fork `GEEKProtocol0110/GEEKProtocol0110` and make a branch.
2. Keep descriptions short, links current and release claims supported by the active project's documentation.
3. Preview the Markdown and banner at desktop and phone widths. Use GitHub-supported HTML only; profile READMEs cannot run scripts or custom CSS.
4. Check local file links, SVG validity and `git diff --check`. Verify changed project links against their actual destinations.
5. Open a pull request describing the visitor-facing change. Include screenshots for banner or layout changes.

Keep the banner as a self-contained SVG with a title and description. Avoid remote fonts, scripts, tracking badges, invented metrics and promised launch dates. Separate live products from experiments and future plans.
