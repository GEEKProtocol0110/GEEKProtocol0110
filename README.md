## The mission

GEEK Protocol began as a way to make learning exciting for one child. Today, its public Alpha lets players test what they know, grow a persistent profile, join live lobbies, and contribute reviewed questions. The wider vision connects learning, competition, characters, and the GEEK ecosystem.

**[geek-protocol-hq](https://github.com/GEEKProtocol0110/geek-protocol-hq)** is the active product repository and source of truth. Start with its [project status](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/docs/PROJECT-STATUS.md) for the current release boundaries.

## What is available

| Surface | Status |
| --- | --- |
| Website, ranked trivia, lobbies, leaderboards, profiles | **Public Alpha** |
| Kasware identity and GEEK fair mint | Implemented non-custodial, user-approved flows |
| Community Content Engine | Alpha question submission, moderation, and first-use credits |
| Alpha GEEK rewards | Internal ledger only; withdrawals and transfers disabled |
| 500-Geek character collection | Design and provenance phase; ownership and collection minting disabled |
| Independent security audit | Not completed; required before treasury-controlled value movement |

Read the [architecture](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/docs/ARCHITECTURE.md), [security policy](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/SECURITY.md), and [audit scope](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/docs/AUDIT-SCOPE.md). Public Alpha features and future value-moving features have different readiness gates.
